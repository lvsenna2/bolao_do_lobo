- v12_games
- v12_predictions

Login:
- Usuário cria conta com nome, e-mail e senha.
- Usuário entra com e-mail e senha.
- ADM tem login fixo.

Antes de usar:
1. Firebase Console > Authentication > Sign-in method > Email/Password > Ativar.
2. Firestore > Regras > cole o conteúdo de firestore.rules e publique.
3. Suba os arquivos no GitHub.
4. Aguarde o deploy.
5. Entre como ADM.
6. Clique em ADM > Dashboard > Cadastrar calendário da Copa.

A versão V12 não usa usuários antigos nem ranking antigo.
